# 國中生複習計畫領航員 (Junior High Study Planner)

專為台灣國中會考與學校段考量身打造的現代化複習計畫前端應用程式。結合艾賓浩斯遺忘曲線回顧排程、五大考科掌握度統計與打卡慶祝動畫。

## 🎯 核心功能特色

- **會考目標倒數計時**：精確計算距離國中教育會考的剩餘天數，強化學習節奏。
- **今日複習清單與打卡**：各科單元打卡、耗時預估、完成即時觸發慶祝特效。
- **艾賓浩斯遺忘曲線提醒**：針對 1 天、3 天、7 天前的重點單元實施黃金記憶回溯。
- **五大考科進度總覽**：國文、英文、數學、自然、社會各科掌控度橫條。
- **本機資料持久化**：使用瀏覽器本機儲存（LocalStorage），離線亦可隨時使用。

## 🛠 技術架構

- **框架**：Vue 3 (Composition API / `<script setup>`)
- **建置工具**：Vite 5
- **樣式庫**：Tailwind CSS 3
- **動態回饋**：Canvas Confetti
- **安全防護**：包含防禦性 DOM Ready State 時序鎖定保護、金鑰隔離機制。

## 🚀 快速啟動

1. **安裝依賴套件**：
   ```bash
   npm install
   ```

2. **啟動本機開發伺服器**：
   ```bash
   npm run dev
   ```

3. **專案打包建置**：
   ```bash
   npm run build
   ```
